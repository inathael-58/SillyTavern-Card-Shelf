# Card Shelf (SillyTavern Extension)

เปิดดูบอทบน JanitorAI จากใน SillyTavern ได้เลย มีแท็บ **Ranking**, **Trending** และ **ล่าสุด** ค้นหาได้ กดนำเข้าเป็นการ์ดของ SillyTavern ได้ในแตะเดียว แล้ว**แปลงลอร์บุ๊คให้เป็นลอร์บุ๊คของ SillyTavern** พร้อมผูกกับตัวละครให้เอง

และมีตัวเลือก **หยุด/ซ่อนแมวเต้นของ Datacat** บนแถบด้านบน สำหรับคนที่ใช้ [Datacat SillyTavern Browser](https://github.com/datacat-run/datacat-sillytavern-browser) แล้วจอกระตุก

- แท็บ Ranking / Trending / ล่าสุด เลื่อนลงเพื่อโหลดเพิ่ม ค้นหาชื่อบอทได้ แสดงอันดับ จำนวนแชท ผู้สร้าง แท็ก และป้าย NSFW
- กดบอทเพื่อดูรายละเอียด แล้วกด **นำเข้าเข้า SillyTavern** หรือ **เปิดใน JanitorAI**
- แท็บ **ลิงก์**: วางลิงก์บอทจาก JanitorAI (หรือ JannyAI) ได้หลายลิงก์ นำเข้าทีเดียว
- แท็บ **ลอร์บุ๊ค**: แปลงลอร์บุ๊คจากที่อื่นให้ใช้ใน SillyTavern ได้ และหาการ์ดที่มีลอร์บุ๊คในตัวแต่ยังไม่ได้แปลง (เช่น การ์ดที่นำเข้าจาก Datacat) แล้วแปลงให้ทีเดียว
- ไอคอนเข็มทิศบนแถบด้านบนเป็นไอคอนนิ่ง ไม่มีแอนิเมชัน หน้าต่างไม่ใช้ blur โหลดรูปเฉพาะที่เลื่อนมาถึง

## ติดตั้ง

ใน SillyTavern เปิด **Extensions → Install extension** แล้ววาง URL นี้:

```
https://github.com/inathael-58/SillyTavern-Card-Shelf
```

### เปิดพร็อกซีของ SillyTavern (จำเป็นสำหรับแท็บ Ranking / Trending)

JanitorAI ไม่ให้เว็บอื่นอ่านรายชื่อบอทตรง ๆ จากเบราว์เซอร์ (CORS) ส่วนขยายจึงอ่านผ่านพร็อกซีที่มีอยู่ใน SillyTavern อยู่แล้ว ต้องเปิดก่อน:

1. เปิดไฟล์ `config.yaml` ในโฟลเดอร์ SillyTavern
2. แก้ `enableCorsProxy: false` เป็น `enableCorsProxy: true`
3. รีสตาร์ท SillyTavern

แล้วไปที่ **Extensions → Card Shelf → การเชื่อมต่อ JanitorAI → ทดสอบการเชื่อมต่อ** ได้ ถ้าไม่เปิดพร็อกซี แท็บรายชื่อจะขึ้นวิธีแก้ให้ แต่แท็บ **ลิงก์** กับ **ลอร์บุ๊ค** ยังใช้ได้ตามปกติ

## เปิดใช้

| ทาง | |
|---|---|
| ไอคอนเข็มทิศ 🧭 บนแถบด้านบน | ปิดได้ในการตั้งค่า |
| เมนูไม้กายสิทธิ์ (Extensions) → Card Shelf | |
| คำสั่ง `/janitor` หรือ `/shelf` | ใส่แท็บต่อท้ายได้: `/janitor trending`, `/janitor latest`, `/janitor link`, `/janitor lore` ใช้ทำปุ่มใน Quick Reply หรือ Quick Dock ได้ |

## นำเข้าบอท

บอทบน JanitorAI มีได้สองแหล่ง ส่วนขยายจะลองตามลำดับที่ตั้งไว้ (ค่าเริ่มต้น JanitorAI ก่อน):

| แหล่ง | ทำงานยังไง | ใช้ได้เมื่อ |
|---|---|---|
| **JanitorAI** | อ่าน definition (personality, scenario, ข้อความแรก, ข้อความแรกสำรอง, ตัวอย่างบทสนทนา) จาก JanitorAI แล้วสร้างการ์ด PNG พร้อมรูปบอท ส่งเข้าระบบนำเข้าการ์ดปกติของ SillyTavern | ผู้สร้างเปิดให้เห็น definition และเปิดพร็อกซีแล้ว |
| **JannyAI** | ใช้ปุ่ม *Import from external URL* ของ SillyTavern เอง ซึ่งดาวน์โหลดสำเนาที่ JannyAI เก็บไว้ | JannyAI มีสำเนาของบอทนั้น ไม่ต้องเปิดพร็อกซี (ถ้าเปิด SillyTavern บนคลาวด์ Cloudflare ของ JannyAI อาจบล็อก) |

การ์ดที่ได้จะเก็บลิงก์ต้นทางไว้ใน Creator's Notes ถ้าผู้สร้างซ่อน definition และ JannyAI ไม่มีสำเนา จะบอกว่านำเข้าไม่ได้เพราะอะไร

## ลอร์บุ๊ค

**หลังนำเข้าบอท** ถ้าการ์ดมีลอร์บุ๊คในตัว (หรือข้อมูลบอทมีลอร์บุ๊คมาด้วย) จะแปลงเป็นลอร์บุ๊คของ SillyTavern แล้วผูกเป็นลอร์บุ๊คหลักของตัวละครให้ทันที เลือกได้ว่าจะ *แปลงเลย*, *ถามก่อน* หรือ *ไม่ต้องทำ* ไม่ทับลอร์บุ๊คที่มีชื่อซ้ำ (ตั้งชื่อใหม่เป็น “ชื่อ (2)”) และไม่แตะตัวละครที่ผูกลอร์บุ๊คไว้แล้ว

**แท็บลอร์บุ๊ค** วาง JSON หรือเลือกไฟล์ แล้วกดสร้าง รับได้:

- ลอร์บุ๊คของ SillyTavern เอง
- `character_book` ของการ์ด V2/V3 หรือการ์ดทั้งใบ (`.json` หรือ `.png`)
- ลอร์บุ๊คที่มากับข้อมูลบอทของ JanitorAI
- NovelAI Lorebook, Agnai Memory Book, RisuAI Lorebook
- รายการ entry ธรรมดา (`keys`/`keywords`/`triggers` + `content`/`text`/`value` …)

เลือกผูกกับตัวละครได้ หรือกด **ดาวน์โหลด JSON** เพื่อเอาไฟล์ไปนำเข้าเอง

**การ์ดที่มีลอร์บุ๊คในตัวแต่ยังไม่ได้แปลง** กดค้นหา แล้วแปลงทีละใบหรือทั้งหมด

## แมว Datacat

ใน **Extensions → Card Shelf → แมว Datacat บนแถบด้านบน**:

| ตัวเลือก | |
|---|---|
| เต้นตามปกติ | ไม่ยุ่งกับ Datacat |
| หยุดนิ่ง | เปลี่ยน GIF เป็นรูปนิ่งเฟรมแรก กดเปิด Datacat ได้เหมือนเดิม |
| ซ่อน | ซ่อนปุ่มบนแถบด้านบน ยังเปิด Datacat ได้จากเมนูไม้กายสิทธิ์ → Explore |

GIF ที่เล่นตลอดทำให้เบราว์เซอร์วาดแถบด้านบนใหม่ทุกเฟรม บางเครื่องรู้สึกกระตุกตอนบอทกำลังพิมพ์ ส่วนขยายนี้ไม่ลบปุ่มของ Datacat (Datacat จะสร้างใหม่ถ้าหายไป) แค่หยุดภาพหรือซ่อนด้วย CSS เลยไม่ทะเลาะกัน

## การตั้งค่าการเชื่อมต่อ (ขั้นสูง)

- **เส้นทาง**: อัตโนมัติ (พร็อกซี SillyTavern → พร็อกซีที่ตั้งเอง → ตรง), เฉพาะพร็อกซี SillyTavern, เฉพาะพร็อกซีที่ตั้งเอง หรือตรงจากเบราว์เซอร์
- **พร็อกซีที่ตั้งเอง**: เช่น `https://your-proxy.example/?url={url}` (พร็อกซีนั้นจะเห็นว่าคุณเปิดดูบอทไหน)
- **API** และค่า **sort** ของแต่ละแท็บ (ค่าเริ่มต้น `popular` / `trending` / `latest`) แก้ได้ ถ้า JanitorAI เปลี่ยนชื่อในอนาคต

## ข้อควรรู้

- ส่วนขยายนี้ไม่ได้มาจาก JanitorAI หรือ JannyAI ถ้า JanitorAI เปลี่ยน API หรือ Cloudflare บล็อก แท็บรายชื่ออาจใช้ไม่ได้ชั่วคราว แท็บลิงก์ยังลองผ่าน JannyAI ได้
- ไม่ส่งแชท API key หรือการตั้งค่าใด ๆ ของ SillyTavern ออกไปไหน ส่งแค่คำขอดูรายชื่อ/ข้อมูลบอทไปที่ JanitorAI (ผ่านพร็อกซีของ SillyTavern ในเครื่องคุณ)
- ไม่ต้องติดตั้ง server plugin ใช้แค่สิ่งที่ SillyTavern มีอยู่แล้ว
