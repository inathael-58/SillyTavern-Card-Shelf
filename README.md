# Card Shelf (SillyTavern Extension)

หน้าต่างเดียว หลายแท็บ: **Datacat**, **JanitorAI**, **Chub** และ **RisuRealm**

| แท็บ | รายชื่อ | กดแล้วได้อะไร |
|---|---|---|
| **JanitorAI** | Trending 24 ชม. / Trending สัปดาห์ / Popular / ล่าสุด | **ส่งไป Datacat** — คัดลอกลิงก์แล้วพาไปแท็บ Datacat ให้ Datacat สร้างการ์ดและนำเข้า (JanitorAI ซ่อนข้อมูลการ์ด ต้องให้ Datacat ดึง) |
| **Chub** | Trending / ดาวน์โหลดมากสุด / ดาวมากสุด / ล่าสุด | **นำเข้า** — ใช้ระบบ "Import from URL" ของ SillyTavern เอง ลอร์บุ๊คที่ฝังในการ์ดมาด้วย |
| **RisuRealm** | Trending / ดาวน์โหลดมากสุด / แนะนำ / ล่าสุด | **นำเข้า** — ดาวน์โหลดไฟล์ `.charx` แล้วส่งเข้าระบบนำเข้าของ SillyTavern ลอร์บุ๊คและรูปอีโมชันมาด้วย |

ทุกแท็บค้นหาได้ เลื่อนลงเพื่อโหลดเพิ่ม นำเข้าเสร็จ Card Shelf เปิดแชทของตัวละครใหม่ให้เลย

และมีตัวเลือก **หยุด/ซ่อนแมวเต้นของ Datacat** บนแถบด้านบน สำหรับคนที่จอกระตุก

## ต้องมี

- [Datacat SillyTavern Browser](https://github.com/datacat-run/datacat-sillytavern-browser) — แท็บ Datacat คือหน้าต่างของ Datacat ตัวนี้
  (ใช้กับแท็บ Datacat และปุ่มส่งไป Datacat ของ JanitorAI · แท็บ Chub กับ RisuRealm ไม่ต้องใช้)
- **เปิดพร็อกซีของ SillyTavern** สำหรับแท็บ JanitorAI: เปิดไฟล์ `config.yaml` ในโฟลเดอร์ SillyTavern แก้ `enableCorsProxy: false` เป็น `enableCorsProxy: true` แล้วรีสตาร์ท SillyTavern
- **RisuRealm:** SillyTavern ที่รองรับไฟล์ `.charx` (เวอร์ชันใหม่ ๆ รองรับแล้ว)

JanitorAI ไม่ให้เบราว์เซอร์อ่านข้อมูลตรง ๆ (CORS) Card Shelf จึงอ่านรายชื่อผ่านพร็อกซีที่มีอยู่ใน SillyTavern แล้ววาดรายชื่อเอง ส่วน Chub กับ RisuRealm อ่านตรงจากเบราว์เซอร์ได้ ไม่ต้องเปิดพร็อกซี (ถ้าเปิดไว้ จะใช้เป็นทางสำรอง)

## ติดตั้ง

ใน SillyTavern เปิด **Extensions → Install extension** แล้ววาง URL นี้:

```
https://github.com/inathael-58/SillyTavern-Card-Shelf
```

### อัปเดต

Extensions → Manage extensions → อัปเดต Card Shelf แล้วกด **โหลดเวอร์ชันล่าสุด** ในแผง Extensions → Card Shelf

เบราว์เซอร์ (โดยเฉพาะ ST ที่เปิดจากไอคอนบนหน้าโฮมของ iPhone) มักเก็บไฟล์เก่าไว้ แม้อัปเดตแล้วก็ยังรันตัวเดิม ปุ่ม **โหลดเวอร์ชันล่าสุด** จะดึงไฟล์ทุกไฟล์ของ Card Shelf จากเซิร์ฟเวอร์ใหม่แล้วโหลดหน้าใหม่ให้

- **ดูเวอร์ชัน:** บรรทัด "ที่รันอยู่" บอกเวอร์ชันที่**รันอยู่จริง** ต่อท้ายด้วยเวอร์ชันที่ติดตั้งไว้บนเซิร์ฟเวอร์
- **ถ้าสองเลขไม่ตรงกัน** จะขึ้นแจ้งเตือนค้างไว้ แตะแจ้งเตือนนั้นเพื่อโหลดใหม่ได้เลย (เช็คตอนเปิด ST และตอนกลับมาที่แท็บ ไม่เกินทุก 10 นาที)
- **ครั้งแรกที่อัปเป็นเวอร์ชันที่มีระบบนี้** ตัวเก่ายังเตือนไม่เป็น ให้ปิดแล้วเปิด ST ใหม่ หรือล้างแคชเบราว์เซอร์เองหนึ่งครั้ง

## ใช้

1. เปิด Card Shelf จากไอคอนเข็มทิศ 🧭 บนแถบด้านบน เมนูไม้กายสิทธิ์ (Extensions) หรือคำสั่ง `/shelf`
2. เลือกแท็บเว็บ แล้วเลือกรายชื่อ (เช่น 🔥 Trending) หรือค้นหาชื่อบอท เลื่อนลงเพื่อโหลดเพิ่ม ปุ่ม ↗ ข้างช่องค้นหาเปิดหน้าเดียวกันบนเว็บนั้น
3. แตะบอทที่ชอบ
   - **JanitorAI:** กด **ส่งไป Datacat** Card Shelf คัดลอกลิงก์ให้แล้วสลับไปแท็บ **Datacat** วางลิงก์ลงในช่องของ Datacat แล้วนำเข้าตามปกติ
   - **Chub / RisuRealm:** กด **นำเข้า** แล้วรอ (RisuRealm แสดงว่าดาวน์โหลดไปกี่ MB จากทั้งหมดเท่าไร กดยกเลิกได้ การ์ดที่มีรูปอีโมชันเยอะใหญ่ได้เป็นร้อย MB)
4. นำเข้าเสร็จ แชทของตัวละครใหม่เปิดขึ้น Card Shelf ปิดเองให้เห็นแชทเลย (ปิดตัวเลือกนี้ได้ในการตั้งค่า) ถ้าการ์ดมีลอร์บุ๊คฝังมา SillyTavern จะถามว่าจะนำเข้าลอร์บุ๊คไหมตามปกติ

ปุ่มอื่นในหน้าบอท: **คัดลอกลิงก์** (เฉย ๆ) และ **เปิดใน …** ถ้าคัดลอกอัตโนมัติไม่ได้ จะมีช่องลิงก์ให้กดค้างคัดลอกเอง

สลับแท็บไปมาได้ รายชื่อกับหน้า Datacat อยู่ที่เดิม ไม่โหลดใหม่ บนมือถือ แท็บที่ไม่ได้เปิดแสดงเป็นไอคอนอย่างเดียว ไม่ใช้แท็บไหน ปิดได้ใน **Extensions → Card Shelf → แท็บ**

คำสั่ง: `/shelf` · `/shelf datacat` · `/shelf janitor` · `/shelf chub` · `/shelf risu` · `/shelf trending24` · `/shelf popular` · `/shelf chub downloads` · `/shelf risu latest` (`/janitor` ก็ได้)

### ถ้ารายชื่อไม่ขึ้น หรือนำเข้าไม่ได้

Card Shelf จะบอกว่าติดอะไรพร้อมวิธีแก้ เช่น พร็อกซียังไม่เปิด หรือ Cloudflare ของเว็บบล็อกเครื่องที่รัน SillyTavern ไปที่ **Extensions → Card Shelf → การเชื่อมต่อ → ทดสอบการเชื่อมต่อ** ได้ (ทดสอบทุกแท็บที่เปิดไว้) ระหว่างนั้นกด **เปิดบนเว็บ …** แล้วดาวน์โหลดการ์ดจากเว็บ มานำเข้าด้วยปุ่มนำเข้าของ SillyTavern (หรือคัดลอกลิงก์ JanitorAI มาวางในแท็บ Datacat) ได้เหมือนกัน

ถ้าเว็บเปลี่ยนที่อยู่ API หรือชื่อการเรียง (sort) ของแต่ละรายชื่อ แก้ได้ในหน้าตั้งค่าเดียวกัน

### Datacat ไม่จำการล็อกอิน

การล็อกอินของ Datacat เก็บอยู่ในหน้า datacat.run ที่อยู่ในกรอบ (ไม่ได้เก็บใน SillyTavern หรือ Card Shelf) เบราว์เซอร์บางตัว โดยเฉพาะ Safari บน iPhone/iPad ไม่ให้เว็บที่อยู่ในกรอบของเว็บอื่นเก็บการล็อกอินไว้ (กันการติดตามข้ามเว็บ) เลยต้องล็อกอินใหม่ทุกครั้ง เป็นแบบเดียวกันไม่ว่าจะเปิด Datacat จาก Card Shelf หรือจากแมวของ Datacat เอง

ถ้ายอมได้: **ตั้งค่า → แอป → Safari → ปิด “ป้องกันการติดตามข้ามไซต์” (Prevent Cross-Site Tracking)** แล้วล็อกอิน Datacat ใหม่อีกครั้ง การตั้งค่านี้มีผลกับทุกเว็บใน Safari

## แมว Datacat

ใน **Extensions → Card Shelf → แมว Datacat บนแถบด้านบน**:

| ตัวเลือก | |
|---|---|
| เต้นตามปกติ | ไม่ยุ่งกับ Datacat |
| หยุดนิ่ง | เปลี่ยน GIF เป็นรูปนิ่งเฟรมแรก กดเปิด Datacat ได้เหมือนเดิม |
| ซ่อน | ซ่อนปุ่มบนแถบด้านบน เปิด Datacat จาก Card Shelf หรือเมนูไม้กายสิทธิ์ → Explore |

GIF ที่เล่นตลอดทำให้เบราว์เซอร์วาดแถบด้านบนใหม่ทุกเฟรม บางเครื่องรู้สึกกระตุกตอนบอทกำลังพิมพ์ Card Shelf ไม่ลบปุ่มของ Datacat (Datacat จะสร้างใหม่ถ้าหายไป) แค่หยุดภาพหรือซ่อนด้วย CSS

## ทำงานยังไง

- แท็บ Datacat คือหน้าต่างของ Datacat SillyTavern Browser เอง (iframe เดิมของมัน พร้อมระบบนำเข้าของมัน) Card Shelf แค่ขอให้ Datacat เปิดหน้าต่าง แล้วย้ายมาวางในแท็บ ไม่ได้คุยกับ datacat.run เอง
- แท็บ JanitorAI อ่านรายชื่อบอทผ่านพร็อกซีของ SillyTavern ในเครื่องคุณ แท็บ Chub กับ RisuRealm อ่านตรงจากเบราว์เซอร์ (พร็อกซีเป็นทางสำรอง) ไม่ส่งแชท API key หรือการตั้งค่าใด ๆ ออกไป
- Chub: ปุ่มนำเข้าเรียก "Import from URL" ของ SillyTavern (`/api/content/importURL`) ตัวเดียวกับปุ่มนำเข้าจากลิงก์ใน SillyTavern
- RisuRealm: ระบบนำเข้า RisuRealm ใน SillyTavern ขอไฟล์ PNG ซึ่ง RisuRealm ไม่ให้ดาวน์โหลดแล้วสำหรับการ์ดส่วนใหญ่ Card Shelf จึงดาวน์โหลดการ์ด (ส่วนใหญ่เป็นไฟล์ `.charx`) ทางเดียวกับแอป RisuAI แล้วส่งเข้าระบบนำเข้าตัวละครของ SillyTavern (`/api/characters/import`) ตัวเดียวกับปุ่มนำเข้าไฟล์
- รายชื่อ RisuRealm มาจาก API ของ RisuRealm ตัวเดียวกับที่แอป RisuAI ใช้ (`sv.risuai.xyz`)

### การ์ดจาก RisuRealm ใน SillyTavern

การ์ดบน RisuRealm ทำมาสำหรับแอป RisuAI ไฟล์ `.charx` เก็บ regex (และบางทีลอร์บุ๊คกับ Lua trigger) ไว้ในไฟล์ `module.risum` ของ RisuAI ซึ่ง SillyTavern ไม่อ่าน Card Shelf จึงช่วยดังนี้:

- **regex:** แปลง regex จาก module (และจากตัวการ์ด) เป็น regex ของตัวละครใน SillyTavern ตอนเปิดแชทครั้งแรก SillyTavern จะถามว่าอนุญาตให้ใช้ไหม
  - editinput → ข้อความผู้ใช้ · editoutput → ข้อความ AI · editprocess → เฉพาะ prompt · editdisplay → เฉพาะที่แสดงผล
- **ลอร์บุ๊ค:** ถ้าตัวการ์ดไม่มีลอร์บุ๊ค แต่ module มี จะใส่ลอร์บุ๊คจาก module ให้
- **การ์ดที่เป็นรูป JPEG ต่อด้วย zip:** ตัดรูปข้างหน้าออกก่อนส่งให้ SillyTavern (ไม่อย่างนั้น SillyTavern เปิดไม่ได้)

**ที่ทำให้ไม่ได้:** คำสั่งเทมเพลตของ RisuAI (CBS เช่น `{{#when::lang::vis::0}}…`), Lua trigger และการแสดงรูปแบบ `<img="…">` ของ RisuAI ไม่มีใน SillyTavern ส่วนนั้นจะขึ้นเป็นข้อความดิบ Card Shelf จะเตือนตอนนำเข้าถ้าการ์ดใช้สิ่งเหล่านี้
